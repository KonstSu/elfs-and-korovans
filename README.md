# Эльфы и корованы

Браузерный 3Д-экшон на Three.js (r128, лежит в `vendor/`). Сборка не нужна.

## Запуск
- Просто откройте `index.html` в браузере (Chrome, Firefox, Safari), **или**
- `npm run serve` и откройте http://localhost:8000

## Что есть
- Три стороны: лесные эльфы, охрана дворца, Злой (имя не придумано).
- 4 зоны: люди (нейтрал, лавка и лекарь), император (дворец), эльфы (густой лес, деревянные домики), Злой (горы, старый форт).
- Лес с LOD: вдали деревья — картинки, вблизи — трёхмерные модели.
- Набеги, шпионы, партизаны, корованы (их можно грабить), приказы командира / задания старейшины, команды армии Злого.
- Увечья: отрубленные руки и ноги (кровотечение — без бинта смерть), выколотые глаза (пол-экрана чёрное), ползание, коляска, протезы. Отрубленные конечности и трупы остаются лежать в 3Д.
- Лавка «как в Daggerfall»: оружие, бинты, зелья, кольчуга, протезы, коляска, наёмники, дом.
- Сохранение: K / F5, загрузка: L / F9 (хранится в браузере).

## Разработка
- `npm test` — тесты логики увечий (`tests/`).
- `npm run check` — проверка синтаксиса всех файлов в `src/`.
